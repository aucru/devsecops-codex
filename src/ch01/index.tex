\section{总述}

本章节依次覆盖 Windows、macOS、Linux 三个平台。

Windows 平台指的是 MicroSoft 出品的 Windows 11 与 Windows 10 操作系统。对于更加古老的 Windows 7 与 Windows XP 操作系统这里不做说明。
同时，Windows 的服务端即 Windows Server 系列产品，经过本人测试，存在软件适配性问题，不推荐在日常工作中使用。
