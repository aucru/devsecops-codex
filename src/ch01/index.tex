\section{总述}

本章节依次覆盖 Windows、macOS、Unix-like 三个平台。

Windows 平台指 Microsoft 出品的 Windows 11 与 Windows 10 操作系统；
更早的 Windows 7 与 Windows XP 已停止官方支持，本书不作说明。
Windows Server 系列经笔者实测存在部分软件适配性问题，不建议作为日常开发环境使用。

macOS 平台指 Apple Inc. 出品的 macOS 操作系统。此操作系统与 Apple Inc. 的 MAC 硬件强绑定，故对于此系统的安装不作说明。
由于 Apple Inc. 的战略决策问题，目前已经全部转向 ARM 架构的 M 系列芯片，对于 x86 平台的旧 MAC 设备将进行淘汰，所以本书只说明 ARM 架构相关的软件。
